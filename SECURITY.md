# Security policy

## Reporting a vulnerability

Do not open an issue for a vulnerability: report it privately, with the [private reporting](https://github.com/lyrixx/nativella/security/advisories/new) of GitHub, on the Security tab of this repository. Only the maintainer reads it.

Say what it affects (the runtime, the `nativella` command, a native API, a PHP package, the files of a release), in which version, and how to reproduce it. The PHP packages are split to read-only repositories (`lyrixx/nativella-php`, `lyrixx/nativella-symfony-bundle`, `lyrixx/nativella-laravel`): report for them here too.

The fix comes in a new release, with the advisory.

## Supported versions

Only the latest release gets the fixes: before 1.0, upgrade to it.
