# Nativella

Run a PHP web application as a desktop or mobile application. Your Symfony,
Laravel or plain PHP project opens in a native window, PHP runs **inside** the
application, and nothing listens on the network: no web server, no TCP port,
no Electron, no Node.

```
system webview ──php://localhost/…──▶ Tauri scheme handler (Rust)
                                        │ public/ file? ─▶ served from disk
                                        ▼
                                      PHP thread ── cookie jar, redirects, URL rewriting
                                        │
                                        ▼
                                      custom SAPI (ext-php-rs) ─▶ public/index.php
                                        │                             │
                    native events ─────▶│◀──── nativella_call() ──────┘
                                        ▼
                         windows, menus, tray, dialogs, clipboard, notifications…
```

- **Any PHP application**: anything with a `public/index.php`. Integrations for
  [Symfony](docs/symfony.md) and [Laravel](docs/laravel.md), or
  [plain PHP](docs/plain-php.md).
- **Native APIs** from PHP: windows, application and context menus, tray icon,
  dialogs, notifications, clipboard, global shortcuts, settings, secrets,
  timers, child processes, power, screens, shell… and typed native events
  (`MenuItemClicked`, `WindowFilesDropped`…). On phones, haptics, geolocation
  and biometrics.
- **State**: an SQLite database in the data directory of the application,
  migrated when it starts (Doctrine, Eloquent).
- **Distribution**: `nativella build` writes one executable that carries the
  project. Android builds work too: see [Mobile](docs/mobile.md).

Nativella is young and experimental, developed on Linux: read
[Limitations and roadmap](docs/limitations.md) first.

## Try it

[Download `nativella`](docs/installation.md#download), for Linux x86_64 or macOS arm64, then,
from a clone of the repository:

```bash
(cd demos/symfony && composer install)
nativella run demos/symfony
```

Or build it from source, on Ubuntu 26.04 ([other systems](docs/installation.md#build-from-source)):

```bash
sudo apt install libphp8.5-embed php8.5-dev php8.5-cli php8.5-sqlite3 \
    libclang-dev libwebkit2gtk-4.1-dev libxdo-dev librsvg2-dev libayatana-appindicator3-1
(cd demos/symfony && composer install)
cargo run -p nativella -- run demos/symfony
```

Or work in Docker, with [Castor](https://castor.jolicode.com):
`castor start`, then `castor qa`. See [Developing Nativella](docs/development.md).

## Repository

| Path | What |
|---|---|
| [`crates/runtime`](crates/runtime) | The runtime: the SAPI, the PHP thread, static files, cookies, redirects, and `nativella_call()`. Framework and GUI agnostic. |
| [`crates/nativella`](crates/nativella) | The shell and the `nativella` command: Tauri windows, the native methods (`src/native/`), events, standalone and mobile bundles. |
| [`packages/nativella`](packages/nativella) | `nativella/nativella`: the PHP API (`Nativella\Window`, `Dialog`, `Menu`…), the events, the fake client for tests. |
| [`packages/symfony`](packages/symfony) | `nativella/symfony-bundle`: services, Symfony events, migrations at boot, profiler panel. |
| [`packages/laravel`](packages/laravel) | `nativella/laravel`: service provider, facades, Laravel events, migrations at boot. |
| [`demos/symfony`](demos/symfony) | Nativella Notes: Symfony 8, Doctrine, menus, tray, context menus, drag and drop. Runs on Android too. |
| [`demos/laravel`](demos/laravel) | Nativella Tasks: Laravel 13, Eloquent. |
| [`demos/vanilla`](demos/vanilla) | Nativella Snippets: no framework, Doctrine DBAL. |
| [`mobile`](mobile) | Android builds: PHP for the phone, staging and build scripts. |
| [`website`](website) | The public website: the landing page, generated by PHP, and the documentation of [`docs`](docs), built by MkDocs. |
