# Static PHP

The working directory of `castor static-php:build` (`.castor/static-php.php`), which builds PHP as a static library with [static-php-cli](https://github.com/crazywhalecc/static-php-cli): the tool, its downloads and sources, and the result, `buildroot/`. Everything here but this file is ignored by Git.

How to use it: [docs/development.md](../docs/development.md#static-php).
